## Learning Progress

Reviewed the module through the counter-width helper function. The current
learning boundary is the following Verilog-2001 code:

```verilog
function integer counter_width;
    input integer value;
    integer remaining;
    begin
        counter_width = 0;
        remaining = value - 1;
        while (remaining > 0) begin
            counter_width = counter_width + 1;
            remaining = remaining >> 1;
        end
        if (counter_width < 1)
            counter_width = 1;
    end
endfunction
```

This function is used during elaboration to calculate the minimum number of
bits needed by the timeout counter. It is not a counter that runs once per
clock and it does not create a separate run-time datapath.

The calculation is equivalent to `ceil(log2(value))`, with a minimum result of
one bit. Subtracting one before the shift loop is important for exact powers of
two. Examples:

| `value` | Required stored range | Function result |
|---:|---:|---:|
| 1 | 0 | 1 bit (minimum legal vector width) |
| 2 | 0 to 1 | 1 bit |
| 4 | 0 to 3 | 2 bits |
| 5 | 0 to 4 | 3 bits |
| 25,000,000 | 0 to 24,999,999 | 25 bits |

For the testbench override `TIMEOUT_CYCLES = 5`, the function starts with
`remaining = 4` and produces three bits after the sequence `4 -> 2 -> 1 -> 0`.
The resulting declaration is therefore equivalent to:

```verilog
reg [2:0] elapsed_cycles;
```
